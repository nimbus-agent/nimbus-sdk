# Python's Ed25519 (RFC-0020 S3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give `nimbus_sdk.signing` an Ed25519 primitive so Python binds all of `manifest-signature.md`, taking it from 23 of 61 conformance cases to 63 of 63 and emptying the repository's only `deferred` map.

**Architecture:** A private `_ed25519.py` implementing RFC 8032 directly — CPython has no stdlib primitive and the zero-dependency rule forbids `cryptography`. Three new public functions over it. The pure layer (`base64url`, `jwk`, `jws`) already exists and is unchanged; only §8 step 10 and §9 steps 5–6 become real rather than absent.

**Tech Stack:** Python 3.11–3.14, stdlib only (`hashlib`, `secrets`). Verified by ruff, `mypy --strict`, and pytest. TypeScript and Go are touched only for goldens, prose and the shared corpus.

**Spec:** [`docs/superpowers/specs/2026-09-05-python-ed25519-s3-design.md`](../specs/2026-09-05-python-ed25519-s3-design.md) — read it before Task 1; its review sibling records findings this plan already incorporates.

## Global Constraints

- **Zero runtime dependencies.** `[project].dependencies` stays empty. `hashlib` and `secrets` are stdlib.
- **`mypy --strict` and `ruff` must pass.** No `Any` at a boundary without a narrowing check.
- **§10's rejection set is closed at exactly ten tokens** — `envelope-malformed`, `base64url-invalid`, `protected-malformed`, `crit-unsupported`, `protected-unknown-member`, `kid-unknown`, `key-unsupported`, `alg-unsupported`, `canonicalization-failed`, `signature-invalid`. **No exception may escape `sign_manifest` or `verify_manifest_signature` that is not a `SignatureError` carrying one of these.** S2 fixed three separate escapes of exactly this kind; do not add a fourth.
- **Every module declares `__stability__ = "experimental"`.** The import-root count stays at **nine** — no new root.
- **`_ed25519.py` is private and stays private.** It is not re-exported from `__init__.py` and does not appear in `docs/api-surface-python.md`.
- **No commit may carry a `!`.** These are additions to an `experimental` module, so the shipment is `feat:`. A squash merge makes the PR title the only subject release-please classifies; a stray `!` fails `commit-guard`, and retitling to satisfy it would spend `@nimbus-dev/sdk` 2.0.0, which RFC-0020 §7 reserves for S5.
- **Reinstall before pytest**: `cd sdks/python && python -m pip install -e .` — `spec_root()` prefers a gitignored bundled snapshot, so without it the suite reads a stale corpus and passes while executing none of your cases.
- **Measured, do not recompute:** one scalar multiplication costs ~51 ms in the reference shape; the full corpus costs ~4.3 s per CI leg. That budget is what licenses the unoptimised implementation.

    malleable = SIG_1[:32] + (s + L).to_bytes(32, "little")

    ("name", "y"),
    [("y == p", P), ("y == p + 1", P + 1), ("y == 2**255 - 1", 2**255 - 1)],

    """§5.1.3 step 1: the encoded y must be canonical, not merely reduce to something."""

def test_a_non_square_does_not_decode() -> None:
    """§5.1.3: if u/v is not a square there is no x, and decoding fails rather than
    computing a bogus coordinate."""

    for candidate in range(2, 400):
        if _ed25519.decode_point(candidate.to_bytes(32, "little")) is None:
            found = True
            break

    a library that raises RecursionError by caller depth is its own defect."""
    import sys

- [ ] **Step 3: Write `_ed25519.py`**

```python
"""Ed25519 (RFC 8032), implemented directly because CPython ships no primitive and the
zero-dependency rule forbids `cryptography`.

**Not constant-time, and deliberately not optimised.** Signing and key generation
multiply by a secret scalar using arbitrary-precision Python integers, which leak
through timing to an attacker able to measure them; see SECURITY.md. Verification
touches only public data, so it carries no such caveat.

The shape follows RFC 8032 §6's published reference — measured at ~51 ms per scalar
multiplication, roughly 4.3 s across the conformance corpus, which is affordable.
RFC-0020 §8 argues the reference de-risks correctness, and that argument only holds
while this resembles it. Point DECODING is the one place that departs: §6's is an
illustration that accepts a non-canonical y and rejects by raising, so decoding follows
§5.1.3 strictly and returns None instead.
"""

from __future__ import annotations

import hashlib

__stability__ = "experimental"

P = 2**255 - 19
"""The field prime, 2**255 - 19."""

L = 2**252 + 27742317777372353535851937790883648493
"""The order of the base point's prime-order subgroup; §5.1.7 requires S < L."""

_D = -121665 * pow(121666, P - 2, P) % P
_SQRT_M1 = pow(2, (P - 1) // 4, P)

_Point = tuple[int, int]
_IDENTITY: _Point = (0, 1)


def _recover_x(y: int, sign: int) -> int | None:
    """§5.1.3 steps 2-3: solve x for a given y, or return None if there is no such x."""
    if y >= P:
        return None
    u = (y * y - 1) % P
    v = (_D * y * y + 1) % P
    x = u * pow(v, 3, P) % P * pow(u * pow(v, 7, P) % P, (P - 5) // 8, P) % P
    vxx = v * x % P * x % P
    if (vxx - u) % P != 0:
        if (vxx + u) % P != 0:
            return None
        x = x * _SQRT_M1 % P
    if x == 0 and sign == 1:
        return None
    if x % 2 != sign:
        x = P - x
    return x


_BASE_Y = 4 * pow(5, P - 2, P) % P
_BASE: _Point = (_recover_x(_BASE_Y, 0) or 0, _BASE_Y)


def decode_point(encoded: bytes) -> _Point | None:
    """§5.1.3, strictly. Returns None rather than raising — an exception here would
    escape manifest-signature.md §10's closed ten-token set."""
    if len(encoded) != 32:
        return None
    value = int.from_bytes(encoded, "little")
    sign = (value >> 255) & 1
    y = value & ((1 << 255) - 1)
    if y >= P:
        return None
    x = _recover_x(y, sign)
    if x is None:
        return None
    return (x, y)


def encode_point(point: _Point) -> bytes:
    x, y = point
    return ((y & ((1 << 255) - 1)) | ((x & 1) << 255)).to_bytes(32, "little")


def _add(first: _Point, second: _Point) -> _Point:
    x1, y1 = first
    x2, y2 = second
    k = _D * x1 % P * x2 % P * y1 % P * y2 % P
    x3 = (x1 * y2 + x2 * y1) * pow(1 + k, P - 2, P) % P
    y3 = (y1 * y2 + x1 * x2) * pow(1 - k, P - 2, P) % P
    return (x3, y3)


def _scalar_mult(point: _Point, scalar: int) -> _Point:
    """Double-and-add, ITERATIVE. The reference recurses once per bit and needs a raised
    recursion limit; a library whose success depends on caller depth is a defect."""
    result = _IDENTITY
    addend = point
    while scalar > 0:
        if scalar & 1:
            result = _add(result, addend)
        addend = _add(addend, addend)
        scalar >>= 1
    return result


def _clamped_scalar(half: bytes) -> int:
    digest = bytearray(half)
    digest[0] &= 248
    digest[31] &= 127
    digest[31] |= 64
    return int.from_bytes(digest, "little")


def publickey_from_seed(seed: bytes) -> bytes:
    """Derive the 32-octet public key. Multiplies by a secret scalar — see the module
    docstring; this leaks through timing exactly as signing does."""
    if len(seed) != 32:
        raise ValueError("an Ed25519 seed is 32 octets")
    digest = hashlib.sha512(seed).digest()
    return encode_point(_scalar_mult(_BASE, _clamped_scalar(digest[:32])))


def sign(seed: bytes, message: bytes) -> bytes:
    if len(seed) != 32:
        raise ValueError("an Ed25519 seed is 32 octets")
    digest = hashlib.sha512(seed).digest()
    a = _clamped_scalar(digest[:32])
    encoded_a = encode_point(_scalar_mult(_BASE, a))
    r = int.from_bytes(hashlib.sha512(digest[32:] + message).digest(), "little") % L
    encoded_r = encode_point(_scalar_mult(_BASE, r))
    k = int.from_bytes(
        hashlib.sha512(encoded_r + encoded_a + message).digest(), "little"
    ) % L
    s = (r + k * a) % L
    return encoded_r + s.to_bytes(32, "little")


def verify(public_key: bytes, message: bytes, signature: bytes) -> bool:
    """§5.1.7. Returns False for every rejection; never raises."""
    if len(public_key) != 32 or len(signature) != 64:
        return False
    s = int.from_bytes(signature[32:], "little")
    if s >= L:  # §5.1.7: S outside [0, L) is invalid, even though S+L is equivalent.
        return False
    a = decode_point(public_key)
    if a is None:
        return False
    r = decode_point(signature[:32])
    if r is None:
        return False
    k = int.from_bytes(
        hashlib.sha512(signature[:32] + public_key + message).digest(), "little"
    ) % L
    return _scalar_mult(_BASE, s) == _add(r, _scalar_mult(a, k))
```

- [ ] **Step 4: Write `manifest_signature.py`**

Implement §8's ten steps **in the documented order** — that order is the contract's principal security property and the corpus pins it case by case. Do not reorder a check for efficiency.

Required shape:

```python
class ManifestSignatureEnvelope(TypedDict):
    protected: str
    signature: str

def generate_signing_key() -> tuple[Jwk, Jwk]: ...
def sign_manifest(manifest: Mapping[str, object],
                  private_key: Jwk) -> ManifestSignatureEnvelope: ...
def verify_manifest_signature(manifest: Mapping[str, object],
                              trusted_keys: Sequence[Jwk]) -> None: ...
```

Points the tests above will hold you to, each mirroring the shipped bindings:

- **Step 1 rejects a non-mapping `manifest`** before touching a member. A `TypeError` escaping to the caller would break §10's closed set exactly as S2's escaping `CanonicalizationError` did.
- **Both envelope members decode before either is parsed** (step 2 precedes step 3).
- **Step 6 skips a candidate whose `jwk_thumbprint` raises `SignatureError`** and continues; anything else propagates. An empty `trusted_keys` is `kid-unknown`.
- **Step 8 checks `alg` only after key resolution**, so an unknown `kid` beats a bogus `alg`.
- **Steps 9 and 10 are last**, and `canonicalize_manifest` is called **outside** any `except` that maps to another token, so `canonicalization-failed` cannot be laundered.
- **§9 step 1 does the correspondence check Go's way**: `_ed25519.publickey_from_seed(d) == base64url_decode(x)`, before canonicalization, with `key-unsupported` on mismatch.
- **Entropy is `secrets.token_bytes(32)`.**
- **`canonicalization-failed` chains**: `raise SignatureError("canonicalization-failed", canonicalization_reason=error.reason) from error`.

- [ ] **Step 2: Derive the vectors, do not transcribe them blind**

**This plan deliberately does not inline the hex.** Writing 1023-byte and 64-byte vectors from recollection into a plan is exactly the failure mode the "measured, do not recompute" rule exists to prevent, and a wrong constant here would become a wrong test in three languages. What follows is a self-checking procedure instead.

RFC 8032 §7.1 publishes, for each vector, a seed, a public key, a message and a signature. Transcribe the **seed and message** from the RFC, then derive the public key and signature with Go's `crypto/ed25519` and confirm they match the RFC's published values:

```go
// throwaway, run from sdks/go
seed, _ := hex.DecodeString("<seed from RFC 8032 §7.1>")
msg, _ := hex.DecodeString("<message from RFC 8032 §7.1>")
priv := ed25519.NewKeyFromSeed(seed)
fmt.Printf("pk  = %x\n", priv.Public().(ed25519.PublicKey))
fmt.Printf("sig = %x\n", ed25519.Sign(priv, msg))
```

If the derived values match the RFC's, the transcription is correct and those are the values for the case file. **If they do not match, the transcription is wrong — fix it; do not adjust anything else.** Deriving with the implementation under test would prove only that it agrees with itself.

## Notes for the executor

**The corpus will not catch a lax point decoder.** Measured during design: all six edge-case public keys in the `ed25519` kind decode successfully under RFC 8032 §6's reference shape, and those cases pass because the *signature* fails, not because the key was refused. `test_ed25519.py` is what pins §5.1.3, and weakening it because "the corpus is green" would remove the only check that exists.

**`is_canonical_s` is the rule a from-scratch implementation gets wrong by default.** The naive verification equation accepts `S + L` because it is the same signature mathematically. The corpus has that case, measured against Go, BoringSSL and OpenSSL — it will catch you, which is why S2 put it there.

**If Python's answer differs from TypeScript's or Go's on any corpus case, stop and report it.** Those two agree with each other today, measured byte for byte. A three-way disagreement on a security primitive is contract-affecting and RFC-gated under `docs/GOVERNANCE.md`; it is not a value to reconcile.
